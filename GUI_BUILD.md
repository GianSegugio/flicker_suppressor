# Flicker Suppressor GUI build

## Development

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\run_gui_dev.ps1
```

## Portable Windows build

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\build_windows.ps1
```

The portable folder is produced under `build\gui_main.dist`.
